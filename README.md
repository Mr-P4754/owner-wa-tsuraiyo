# 『オーナーはつらいよ』(owner-wa-tsuraiyo)

ビルオーナーとなり、**「15年間（60ターン）破産せずにビルを維持し続ける」**ことを目指す3Dビル経営シミュレーションゲームです。

## 主な特徴・ゲームシステム

* **Three.js による3Dビル断面＆マルチデバイス対応UI**
  * 季節（春・夏・秋・冬）に応じて背景とライティングが変化する3Dビルビューを搭載。ドラッグで回転、各フロアをタップして入居者詳細・発生中トラブル・空室審査へ即座にアクセスできます。
* **目利き（見た目と中身のギャップ）の入居審査（全140パターン）**
  * 見た目・肩書きが「優良そう」でも内部属性が「悪人・反社・クレーマー」である一方、「ヤンキー・怪しい」風貌でも実は人情味あふれる「善人・優良住民」であるケースが存在します。
  * 1組 **50万円** の**興信所調査**を活用し、入居前に本性を見抜くことができます。
* **階層別の固定維持費・税金・次期家賃改定のトレードオフ**
  * 空室率に関わらず毎ターン **350万円**（低層12万×5F＝60万／中層30万×3F＝90万／高層100万×2F＝200万）の固定維持費が発生します。
  * 利益に対して **`max(0, 収入 － (維持費 ＋ 積立費)) × 30%`** の税金が課されます（修繕積立金への振替により節税が可能）。
  * 財務タブから**「次期家賃」の5％増額／5％減額**を選択でき、家賃収入と全室信頼度（±10）・ビル評判（±4）のトレードオフをコントロールできます。
* **経年劣化に連動するトラブル発生率＆緊急大規模改修**
  * 基本トラブル率は $\min(60\%,\; 5\% + \text{経過期数} \times 2.5\%)$ で上昇し、1入居者あたり複数件同時発生することもあります。
  * トラブル対応費用は階層に応じて高騰します（低層×1.0倍／中層×2.2倍／高層×4.0倍）。
  * 低確率（$\min(10\%,\; 5\% + \text{経過期数} \times 0.25\%)$）でビル全館の**緊急大規模改修トラブル**が発生し、ビル断面が赤色アラート点滅します。
* **5年（20ターン）ごとの定期大規模修繕＆任意の臨時大規模改修**
  * 5年目（1,500万円）、10年目（2,500万円）、15年目（4,000万円）に定期大規模修繕が発生します。
  * 入居率と住民の信頼度に応じて**「住民協力金」**が集まり、また5年を待たずに任意のタイミングで**臨時大規模改修**を実施してトラブル発生率を初期値（5%）へ引き下げることも可能です。

## フロア構造（全10階）

| 階層区分 | フロア | ターゲット層 | 適正家賃 | 固定維持費 | トラブル費倍率 | 特徴 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **🏠 低層階** | 1〜5階 | ファミリー・一般 | 40万円 | 12万円/室 | ×1.0倍 | 応募が多いが玉石混交。入居5年で「高齢世帯」へ変化（滞納リスクと修繕協力ボーナス）。 |
| **💼 中層階** | 6〜8階 | オフィス・テナント | 120万円 | 30万円/室 | ×2.2倍 | 収益の柱。毎年「春」に業績判定があり、家賃増減交渉が発生。反社・特殊詐欺の混入リスクあり。 |
| **👑 高層階** | 9〜10階 | 富裕層ペントハウス | 300万円 | 100万円/室 | ×4.0倍 | 高収益だが維持費・トラブル解決費が非常に高額。ビル評判が40未満になると応募が0%になる。 |

## 公開・実行方法

### GitHub Pages でのホスティング
外部ビルドツール（Webpack等）に一切依存していないため、本リポジトリをそのまま GitHub にプッシュし、**Settings > Pages** から対象ブランチ（`main` / root）を選択するだけで即座に公開できます。

### ローカル環境での動作確認
ES6 Modules (`<script type="module">`) を使用しているため、ローカルで開く際は簡易HTTPサーバー経由でアクセスしてください。

```bash
# Python 3 がインストールされている場合
python -m http.server 8000

# Node.js (npx) を使用する場合
npx serve .
```
ブラウザで `http://localhost:8000` を開くとプレイできます。
